# Siddeshwara Electricals

This website is a modern catalog platform for Siddeshwara Electricals, designed to showcase the company’s products, projects, and work portfolio in a clean and professional way. It helps visitors quickly understand the business, view company-related details, and browse work samples with images and structured information.

## About the Website

The project is built as a Next.js web application with a catalog-based admin system. It allows the business owner to manage:

- Company information
- Product or service categories
- Work/project details
- Images and related content
- Catalog data stored in MongoDB

The main goal is to make the business easier to present online and easier to update without needing technical help.

## What It Contains

### Company-related items
These are the details connected to the company itself, such as:

- Company name and branding
- Contact information
- Business profile
- Short description of the company
- General catalog or informational data

To add or update these items, the admin section can be used to edit the stored catalog data. The company information is managed through the application and saved to the database.

### Work-related items
These are project or work entries that show what the company has done, such as:

- Project names
- Work categories
- Descriptions
- Images related to completed projects
- Portfolio-style presentation for customers

These work items can be added or updated through the admin panel and then appear on the website automatically.

## How to Add Items

### Company data
1. Open the admin section in the website.
2. Log in with the admin credentials.
3. Navigate to the catalog or company management section.
4. Add or edit the company details.
5. Save the changes.
6. Refresh the website to view the updated information.

### Work data
1. Open the admin section.
2. Go to the works or project section.
3. Enter the project title, description, and relevant information.
4. Upload or attach images if needed.
5. Save the entry.
6. The homepage or catalog page should reflect the new work item.

## Technologies Used

This project uses:

- Next.js for the website frontend and backend routes
- React for UI components
- TypeScript for type-safe application development
- MongoDB for storing catalog and site data
- Node.js and server-side API routes for data handling
- CSS and component-based styling for the website design
